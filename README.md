# DSA in Java – Part 07: Stacks and Questions

This repository contains my Java implementations and problem-solving practice focused on **Stacks**, an important linear data structure in Data Structures and Algorithms.

## 📚 Topics Covered

- Introduction to Stack Data Structure
- Stack Implementation Using Arrays
- Stack Implementation Using ArrayList
- Stack Implementation Using LinkedList
- Push and Pop Operations
- Peek and isEmpty Operations
- Stack Overflow and Underflow
- Reversing a Stack
- Reversing a String Using Stack
- Next Greater Element
- Stock Span Problem
- Valid Parentheses
- Practice Problems Based on Stacks

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Stack, Arrays, ArrayList, LinkedList, Recursion, Java Collections Framework

## 🎯 Learning Objectives

- Understand the LIFO (Last In, First Out) principle.
- Learn stack operations and their implementations.
- Solve important stack-based coding problems.
- Improve problem-solving skills and DSA fundamentals.

